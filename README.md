# Практическая работа: решение СЛАУ (вариант 18)

Проект на Node.js (ES6-модули). Для двух систем 4×4 из задания:

- прямые методы: Гаусса, Крамера, Гаусса–Жордана;
- обратная матрица, нормы, число обусловленности `cond∞(A)`;
- итерационные методы Якоби и Зейделя, проверка сходимости (`‖B‖∞`, спектральный радиус `ρ`);
- дополнительно — итерации для `AᵀAx = Aᵀb` (для неё метод Зейделя сходится);
- графики невязки `‖Ax − b‖∞` по итерациям (SVG).

## Запуск

Нужен Node.js 18 или новее.

```bash
npm install
npm start          # обычный расчёт: node src/index.js
npm run start:random   # исследование при изменении A и b: node src/random.js
```

Библиотеки: `d3-scale`, `d3-shape`, `d3-array` (графики), `cli-table3` (таблицы в консоли).
Алгоритмы решения написаны в проекте самостоятельно.

## Входные данные

Матрицы `A` и `b` (а также точное решение и параметры) задаются в файле `input/data.json`.
Точность `ε`, число прогонов и пределы варьирования — там же, в блоке `params`.

## Структура

```
input/data.json  входные матрицы A и b, точное решение, параметры расчёта
src/solvers.js   все методы: Гаусс, Крамер, Гаусс–Жордан, обратная матрица, Якоби, Зейдель, ρ
src/chart.js     SVG-график невязки
src/data.js      загрузка input/data.json
src/index.js     обычный расчёт: вывод таблиц, сохранение результатов
src/random.js    исследование при случайном изменении A и/или b в пределах ±1%
output/          создаётся при запуске
  results.json         все результаты обычного расчёта
  random-results.json  статистика случайных прогонов
  system1.svg, system2.svg             невязка Якоби и Зейделя для исходных систем
  system1-AtA.svg, system2-AtA.svg     то же для AᵀAx = Aᵀb
```

Точность итераций `ε = 1e-6` и другие параметры — в `input/data.json` и в `iterate()`.

## Исследование при изменении A и b

`npm run start:random` методом Монте-Карло многократно (по умолчанию 1000 раз) случайно
изменяет элементы матрицы `A` и вектора `b` в пределах ±1% и запускает все алгоритмы.
Рассматриваются три случая: меняется только `A`, только `b`, и `A` и `b` вместе. Для
каждого случая выводится статистика: `cond(A)`, спектральные радиусы, ошибка `‖x − x*‖`
и невязка прямых методов, а также сходимость и число итераций методов Якоби и Зейделя
(в т.ч. для `AᵀAx = Aᵀb`). Генератор случайных чисел детерминирован (`seed` в
`input/data.json`), поэтому прогоны воспроизводимы.

Если в `input/data.json` не задано поле `exactSolution`, роль опорного решения `x*`
берёт на себя лучшее вычисленное значение — решение исходной системы прямым методом
Гаусса–Жордана. Об этом выводится предупреждение, а все ошибки `‖x − x*‖` считаются
относительно него.
